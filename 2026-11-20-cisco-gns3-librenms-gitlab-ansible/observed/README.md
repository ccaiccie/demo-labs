# Observed evidence, not desired configuration
All committed examples are synthetic, sanitized fixtures. They are NOT exports from a real lab.
`lab-r1.cfg` illustrates an Cisco IOSv configuration excerpt. `lab-r1.json` is its minimal normalized record, not a full configuration backup.
Real raw backups belong in restricted storage outside this repository. Before importing any evidence, remove passwords, hashes, community strings, keys, tokens, private addresses and identifying data; manually review the sanitized result.
LibreNMS can provide discovery/monitoring evidence; Oxidized can supply versioned configuration backups. Neither should silently overwrite desired intent.
